# Tell a Whole Story in 32 Characters — make.fun entry

One Wi-Fi network name, 32 characters or fewer, that lands a joke and
implies a whole story:

> MyWiFiChoseMyExOverMe

21 characters. After a breakup, even the household Wi-Fi picked sides —
it chose the ex over the speaker. A passer-by reading the network list
gets the joke on the first read and can fill in the rest of the story.

`main.py` writes that single name to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(falling back to the script directory), with a self-gate assert matching
the kit's 1–32 character, single-line rule plus a plain-ASCII check so
the name works as a real SSID.
